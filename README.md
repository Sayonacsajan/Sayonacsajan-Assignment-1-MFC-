# Mathematics for Computing – Assignment 1

## 📚 Overview

This repository contains my **Mathematics for Computing – Assignment 1** prepared using **LaTeX Beamer**.

The presentation covers fundamental concepts related to **Sets, Set Builder Form, Inclusion–Exclusion Principle, and Partially Ordered Sets (Posets)**.
